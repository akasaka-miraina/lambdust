### 1.3 ライフタイム制約最適化

**問題**: 過剰な`'static`制約によるメモリ効率低下

**最適化対象**:
- 型環境のライフタイム管理
- 値のライフタイム制約削除
- 副作用システムの寿命最適化

**実装戦略**:
```rust
// Before: 過剰な'static制約
struct TypeEnvironment<T: 'static> { /* ... */ }

// After: 必要最小限のライフタイム
struct TypeEnvironment<'a, T: TypeRepr + 'a> { /* ... */ }
```

**最適化効果**:
- メモリ使用量削減 (推定15-20%)
- コンパイル時間短縮
- 実行時性能向上

**依存関係**: 1.1, 1.2完了必須  
**完了条件**: ライフタイム制約最適化・テスト通過
