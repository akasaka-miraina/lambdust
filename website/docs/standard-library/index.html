Standard Library

Lambdust's standard library provides a comprehensive set of functions and data structures for functional programming, following R7RS Scheme standards while adding modern type-safe extensions.

Library Organization

The standard library is organized into logical modules, each focusing on specific functionality:

Lists

Comprehensive list operations including map, filter, fold, and SRFI-1 extensions.

(map square '(1 2 3 4))
(filter even? numbers)
(fold-left + 0 values)

Strings

Unicode-aware string processing with efficient manipulation functions.

(string-upcase "hello")
(string-split "a,b,c" ",")
(string-contains? str pattern)

Mathematics

Complete numeric tower with arbitrary precision and mathematical functions.

(sin (/ pi 2))
(gcd 24 36)
(exact->inexact 22/7)

Input/Output

Safe I/O operations with proper effect tracking and error handling.

(read-file "data.txt")
(write-file "output.txt" content)
(with-input-file "input.txt" ...)

System

System interaction, process management, and environment access.

(getenv "PATH")
(current-directory)
(system "ls -la")

Vectors & Arrays

Efficient array operations with bounds checking and SIMD support.

(make-vector 10 0)
(vector-ref vec index)
(vector-map f vector)

Core Principles

Type Safety

All standard library functions are fully typed with precise type signatures:

;; Typed list operations
(map : (∀ α β. (α → β) → List α → List β))
(filter : (∀ α. (α → Boolean) → List α → List α))
(fold-left : (∀ α β. (β → α → β) → β → List α → β))

;; Safe array access
(vector-ref : (∀ α (n : Nat) (i : Nat). 
               Vector n α → (i < n) → α))

Effect Tracking

Functions with side effects are clearly marked in their types:

;; Pure functions (no effects)
(+ : (Number → Number → Number))
(string-length : (String → Nat))

;; I/O functions (explicit effects)
(println : (String → IO Unit))
(read-file : (String → IO String))

;; State functions (state effects)
(get-random : (Random Integer))
(current-time : (Time Timestamp))

R7RS Compliance

Full compatibility with Scheme R7RS standard while adding type safety:

;; R7RS-compliant list operations
(car '(1 2 3))           ; Result: 1
(cdr '(1 2 3))           ; Result: (2 3)
(cons 1 '(2 3))          ; Result: (1 2 3)

;; Enhanced with type safety
(car : (∀ α. Pair α β → α))
(cdr : (∀ α β. Pair α β → β))
(cons : (∀ α β. α → β → Pair α β))

Common Usage Patterns

List Processing

;; Transform data
(define numbers '(1 2 3 4 5))
(define squares (map (lambda (x) (* x x)) numbers))
(define evens (filter even? numbers))
(define sum (fold-left + 0 numbers))

;; List comprehension style
(define even-squares 
  (map square (filter even? numbers)))

;; Pipeline style with threading
(-> numbers
    (filter even?)
    (map square)
    (fold-left + 0))

String Operations

;; String manipulation
(define text "Hello, Lambdust World!")
(define words (string-split text " "))
(define upper (string-upcase text))
(define length (string-length text))

;; String formatting
(define greeting 
  (string-append "Hello, " name "!"))

;; Pattern matching
(define email-valid?
  (string-match? email "^[^@]+@[^@]+\\.[^@]+$"))

I/O Operations

;; File operations with error handling
(define read-config : (String → IO (Either Error Config))
  (lambda (filename)
    (with-handler
      [(IOError e) → (return (Left e))]
      (do-io
        [content ← (read-file filename)]
        [config ← (parse-config content)]
        (return (Right config))))))

;; Safe resource management
(define process-file : (String → String → IO Unit)
  (lambda (input-file output-file)
    (with-input-file input-file
      (lambda (in-port)
        (with-output-file output-file
          (lambda (out-port)
            (copy-port in-port out-port)))))))

Integration with Type System

Gradual Typing Support

;; Dynamic usage (no type annotations)
(map square numbers)

;; Gradually typed
(map : (Number → Number) square : (List Number) numbers)

;; Fully typed
(map : (Number → Number) 
     : (lambda ((x : Number)) : Number (* x x))
     : (List Number) numbers)

Dependent Type Integration

;; Length-indexed operations
(define safe-head : (∀ α (n : Nat). Vector (+ n 1) α → α)
  (lambda (vec) (vector-ref vec 0)))

;; Matrix operations with dimension checking
(define matrix-multiply : (∀ (a b c : Nat) (T : Type).
                           Matrix a b T → Matrix b c T → Matrix a c T)
  (lambda (m1 m2) ...))
