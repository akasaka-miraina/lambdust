Complete reference documentation for all Lambdust functions, types, and modules. This reference includes precise type signatures, effect annotations, and usage examples.

Quick Reference

Most Commonly Used Functions

Function Type Signature Description
map ∀ α β. (α → β) → List α → List β Apply function to each list element
filter ∀ α. (α → Boolean) → List α → List α Select elements matching predicate
fold-left ∀ α β. (β → α → β) → β → List α → β Reduce list from left to right
cons ∀ α. α → List α → List α Prepend element to list
car ∀ α. List α → α Get first element of list
cdr ∀ α. List α → List α Get rest of list after first element

Type Notation

Type signatures use the following notation:

  • α, β, γ - Type variables (polymorphic types)
  • → - Function type constructor
  • ∀ - Universal quantification
  • Π - Dependent function types
  • Σ - Dependent pair types
  • IO, State, Error - Effect annotations

Function Documentation Format

Each function in the API reference follows this format:

Example Function Documentation

function-name

Type: (signature here)

Description: Brief description of what the function does.

Parameters:

  • param1 - Description of first parameter
  • param2 - Description of second parameter

Returns: Description of return value

Effects: Any side effects (IO, State, etc.)

Examples:

(function-name arg1 arg2)  ; Expected result

Built-in Effects

Effect Description Operations

API Stability

Lambdust is under active development. While core language features are stable, some advanced APIs may change between versions. Check the changelog when upgrading.
