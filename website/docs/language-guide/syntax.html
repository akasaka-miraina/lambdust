Syntax & Semantics

Lambdust's syntax is based on Scheme's S-expressions but extended with modern type annotations, pattern matching, and other advanced features while maintaining full R7RS compatibility.

expr ::= atom | list | type-expr | pattern-match

Basic Syntax

S-expressions

Lambdust uses S-expressions (symbolic expressions) as its fundamental syntax:

Basic S-expressions

;; Atoms (basic values)
42                    ; Integer
3.14                  ; Real number
#t                    ; Boolean true
#f                    ; Boolean false
"hello"               ; String
'symbol               ; Symbol
#\a                   ; Character

;; Lists (function applications and data)
(+ 1 2 3)             ; Function application
'(1 2 3 4)            ; Quoted list (data)
(define x 42)         ; Definition
(lambda (x) (* x x))  ; Function definition

Comments

;; Single-line comment

#| Multi-line
   comment spanning
   multiple lines |#

#;(this entire s-expression is commented out)

Data Types

Numbers

;; Integers
42
-17
#b1010      ; Binary: 10
#o755       ; Octal: 493
#x1a2b      ; Hexadecimal: 6699

;; Real numbers
3.14
-2.5
1e6         ; Scientific notation: 1000000
1.5e-3      ; 0.0015

;; Rational numbers
1/3
22/7

;; Complex numbers
3+4i
1.5-2.7i

Strings and Characters

;; Strings
"Hello, world!"
"String with \"escaped\" quotes"
"Unicode: λ α β γ"
"Multiline string
spans multiple
lines"

;; Characters
#\a          ; Letter 'a'
#\space      ; Space character
#\newline    ; Newline character
#\λ          ; Unicode lambda

Collections

;; Lists
'()                   ; Empty list
'(1 2 3)              ; List of numbers
'(a b c)              ; List of symbols
(list 1 2 3)          ; List constructor

;; Vectors (arrays)
#()                   ; Empty vector
#(1 2 3)              ; Vector of numbers
(vector 'a 'b 'c)     ; Vector constructor

;; Pairs (cons cells)
'(1 . 2)              ; Pair of 1 and 2
(cons 'a 'b)          ; Cons constructor

Type Annotations

Lambdust extends Scheme syntax with optional type annotations:

Type Annotation Syntax

;; Variable type annotations
(define x : Integer 42)
(let ([count : Integer 0]) ...)

;; Function type annotations
(define add : (Integer → Integer → Integer)
  (lambda ((x : Integer) (y : Integer))
    (+ x y)))

;; Polymorphic types
(define identity : (∀ α. α → α)
  (lambda (x) x))

;; Dependent types
(define safe-head : (∀ α. (lst : List α) → (length lst > 0) → α)
  (lambda (lst proof) (car lst)))

Type Expression Syntax

;; Basic types
Integer               ; Integer type
Real                  ; Real number type
String                ; String type
Boolean               ; Boolean type

;; Function types
(A → B)               ; Function from A to B
(A → B → C)           ; Curried function: A → (B → C)

;; Polymorphic types
(∀ α. α → α)          ; Universal quantification
(∀ (α : Kind). Type)  ; Bounded quantification

;; Dependent types
(∀ (n : Nat). Vector n α)     ; Vector of length n
(x : Integer) → (x > 0) → ... ; Dependent function type

;; Type constructors
(List α)              ; List of α
(Maybe α)             ; Optional value
(Either α β)          ; Sum type

Function Definition

Lambda Expressions

;; Basic lambda
(lambda (x) (* x x))

;; Multiple parameters
(lambda (x y z) (+ x y z))

;; Typed parameters
(lambda ((x : Integer) (y : Integer)) (+ x y))

;; Rest parameters
(lambda (first . rest) (cons first rest))

;; Optional parameters with defaults
(lambda (x [y 0] [z 1]) (+ x y z))

Function Definitions

;; Simple definition
(define square (lambda (x) (* x x)))

;; Shorthand syntax
(define (square x) (* x x))

;; With type annotations
(define square : (Number → Number)
  (lambda ((x : Number)) (* x x)))

;; Shorthand with types
(define (square (x : Number)) : Number
  (* x x))

Pattern Matching

Lambdust provides powerful pattern matching capabilities:

Pattern Matching Syntax

;; Basic match expression
(match value
  [0 "zero"]
  [1 "one"]  
  [n "many"])

;; List patterns
(match lst
  ['() "empty"]
  [(cons h t) (format "head: ~a, tail: ~a" h t)]
  [other "not a list"])

;; Constructor patterns
(match option
  [(Some x) x]
  [None 0])

;; Guard patterns
(match n
  [x (when (> x 0)) "positive"]
  [x (when (< x 0)) "negative"]
  [0 "zero"])

Pattern Types

;; Literal patterns
[42 "forty-two"]      ; Match exact number
["hello" "greeting"]  ; Match exact string
[#t "true"]           ; Match boolean

;; Variable patterns
[x (+ x 1)]           ; Bind to variable x
[_ "ignored"]         ; Wildcard pattern

;; Constructor patterns
[(Point x y) (+ x y)] ; Destructure Point
[(cons h t) h]        ; Destructure list

;; List patterns
[() "empty"]          ; Empty list
[(list x) x]          ; Single element
[(list x y z) (+ x y z)] ; Three elements

Control Flow

Conditionals

;; if expression
(if (> x 0) "positive" "non-positive")

;; cond expression
(cond
  [(> x 0) "positive"]
  [(< x 0) "negative"]
  [else "zero"])

;; when and unless
(when (> x 0) (display "positive"))
(unless (zero? x) (display "non-zero"))

Loops and Iteration

;; Named let (recursion)
(let loop ([n 10] [acc 1])
  (if (zero? n) acc
      (loop (- n 1) (* acc n))))

;; do loop
(do ([i 0 (+ i 1)]
     [sum 0 (+ sum i)])
    ((>= i 10) sum))

;; for comprehensions
(for/list ([x (in-range 10)])
  (* x x))

Module System

Library Definition

;; Define a library
(define-library (example math)
  (import (scheme base))
  (export factorial fibonacci)
  
  (begin
    (define (factorial n)
      (if (<= n 1) 1
          (* n (factorial (- n 1)))))
    
    (define (fibonacci n)
      (if (< n 2) n
          (+ (fibonacci (- n 1))
             (fibonacci (- n 2)))))))

Imports and Exports

;; Import library
(import (example math))

;; Selective import
(import (only (scheme base) + - * /))

;; Renaming import
(import (rename (scheme base) (+ plus) (- minus)))

;; Prefix import
(import (prefix (scheme base) scheme:))

Advanced Syntax

Macros

;; Simple macro
(define-syntax-rule (when condition body ...)
  (if condition (begin body ...)))

;; Pattern-based macro
(define-syntax define-getter
  (syntax-rules ()
    [(define-getter name field)
     (define (name obj) (field obj))]))

;; Syntax-case macro
(define-syntax with-values
  (lambda (stx)
    (syntax-case stx ()
      [(with-values producer consumer)
       #'(call-with-values (lambda () producer) consumer)])))

Quasiquotation

;; Template construction
(define (make-setter name)
  `(define (,(string->symbol (string-append "set-" name "!")) obj val)
     (set! (,name obj) val)))

;; Unquote and unquote-splicing
(let ([x 42] [lst '(a b c)])
  `(the value is ,x and the list is ,@lst))
;; Result: (the value is 42 and the list is a b c)

Type System Integration

Gradual Typing Syntax

;; Dynamic type
(define process-input : (Dynamic → Dynamic)
  (lambda (input) ...))

;; Blame labels
(define safe-divide : (Number → Number → Number)
  (contract (Number → Number → Number)
            unsafe-divide
            #:blame-positive "caller"
            #:blame-negative "safe-divide"))

;; Type ascription
(: expression Expected-Type)

Effect Annotations

;; Pure function (default)
(define pure-computation : (Integer → Integer)
  (lambda (x) (* x x)))

;; IO effects
(define interactive : (String → IO String)
  (lambda (prompt)
    (display prompt)
    (read-line)))

;; State effects
(define stateful : (Integer → State Counter Integer)
  (lambda (n)
    (do [current ← get-counter]
        [_ ← (set-counter (+ current n))]
        (return current))))

Syntax Rules and Conventions

Naming Conventions

  • Predicates: End with ? (e.g., number?, empty?)
  • Mutators: End with ! (e.g., set!, vector-set!)
  • Type constructors: CamelCase (e.g., Maybe, Either)
  • Functions: kebab-case (e.g., string-append, list-ref)
  • Constants: All caps with dashes (e.g., PI, MAX-INT)

Style Guidelines

;; Preferred indentation
(define (long-function-name parameter-one 
                            parameter-two
                            parameter-three)
  (let ([intermediate-result (complex-computation parameter-one
                                                  parameter-two)])
    (final-step intermediate-result parameter-three)))

;; Line breaks for readability
(cond
  [(very-long-condition-that-spans-multiple-words? x y z)
   (correspondingly-long-action x y z)]
  [(another-condition? a b)
   (shorter-action a b)]
  [else
   (default-action)])

Operator Precedence

Lambdust uses consistent S-expression syntax with no operator precedence issues:

;; All operations are explicit function calls
(+ 1 (* 2 3))         ; 1 + (2 * 3) = 7
(* (+ 1 2) 3)         ; (1 + 2) * 3 = 9

;; Comparison and logical operations
(and (> x 0) (< x 10))
(or (= x 0) (= x 1))
(not (empty? lst))

Error Handling Syntax

;; Exception handling
(with-exception-handler
  (lambda (condition)
    (display "Error occurred: ")
    (display condition))
  (lambda ()
    (risky-operation)))

;; Error values with Maybe/Either
(match (safe-divide x y)
  [(Right result) result]
  [(Left error) (handle-error error)])

;; Guard expressions
(guard (condition
        [(file-error? condition) 'file-error]
        [(network-error? condition) 'network-error]
        [else (raise condition)])
  (perform-io-operation))
