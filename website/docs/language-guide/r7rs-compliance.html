R7RS Compliance

Lambdust is fully compliant with the Scheme R7RS-small standard and includes many R7RS-large libraries, providing compatibility with existing Scheme code while adding modern type system features.

R7RS ⊂ Lambdust — Full R7RS compatibility with modern extensions

R7RS-small Compliance

Lambdust implements the complete R7RS-small specification:

Standard Scheme Features

;; Basic syntax and semantics
(define (factorial n)
  (if (<= n 1) 1
      (* n (factorial (- n 1)))))

;; Lexical scoping
(let ([x 10])
  (let ([f (lambda (y) (+ x y))])
    (f 5)))  ; Result: 15

;; Proper tail calls
(define (count-down n)
  (if (= n 0) 'done
      (count-down (- n 1))))  ; Tail-recursive

;; First-class continuations
(call/cc 
  (lambda (k)
    (+ 1 (k 2))))  ; Result: 2

Modern Extensions

Lambdust extends R7RS with modern programming language features while maintaining compatibility:

Type Annotations

Optional Type Safety

;; Standard R7RS (works unchanged)
(define (square x) (* x x))

;; With Lambdust type annotations
(define square : (Number → Number)
  (lambda ((x : Number)) (* x x)))

;; Gradual typing - mix as needed
(define (process-data data)
  (let ([validated : (List Integer) (validate-integers data)])
    (map square validated)))

Enhanced Syntax

;; Pattern matching (extension)
(match value
  [0 "zero"]
  [n (string-append "number: " (number->string n))])

;; Do-notation for monads (extension)
(do-io
  [line ← (read-line)]
  [_ ← (display "You entered: ")]
  (display line))

;; Type definitions (extension)  
(define-type (Maybe α)
  (Some α)
  (None))

Core Foundation SRFIs

Essential data structure and algorithm libraries that form the foundation of functional programming:

✓ SRFI-1: List Library

Comprehensive list processing operations

(import (srfi 1))
(filter even? '(1 2 3 4 5))     ; (2 4)
(partition even? '(1 2 3 4 5))  ; ((2 4) (1 3 5))
(take '(a b c d e) 3)           ; (a b c)

Key procedures: filter, partition, fold-left, fold-right, take, drop, split-at, any, every, list-index, delete-duplicates

✓ SRFI-13: String Library

Unicode-aware string processing

(import (srfi 13))

(string-split "a,b,c" ",")          ; ("a" "b" "c")
(string-contains? "hello" "ell")    ; 1
(string-pad "42" 5 #\0)             ; "00042"

Key procedures: string-trim, string-pad, string-split, string-join, string-contains?, string-take, string-drop, string-tokenize

✓ SRFI-43: Vector Library

Efficient vector operations

Associative data structures

Module System

Lambdust's module system is fully compatible with R7RS libraries:

R7RS Library Definition

;; Standard R7RS library
(define-library (example utils)
  (import (scheme base)
          (scheme write))
  (export fibonacci square)
  
  (begin
    (define (fibonacci n)
      (if (< n 2) n
          (+ (fibonacci (- n 1))
             (fibonacci (- n 2)))))
    
    (define (square x) (* x x))))

;; Usage
(import (example utils))
(display (fibonacci 10))   ; Uses imported procedure

Enhanced Module Features

;; Lambdust module extensions
(define-library (example typed-utils)
  (import (scheme base)
          (lambdust types))     ; Type system integration
  (export typed-fibonacci : (Integer → Integer))
  
  (begin
    (define typed-fibonacci : (Integer → Integer)
      (lambda ((n : Integer))
        (if (< n 2) n
            (+ (typed-fibonacci (- n 1))
               (typed-fibonacci (- n 2))))))))

;; Conditional compilation
(cond-expand
  [lambdust
   (import (lambdust types))]
  [else
   (import (scheme base))])

Easy migration from other Scheme implementations:

  1. Direct Port: Most R7RS code works unchanged
  2. Library Updates: Update library imports to Lambdust equivalents
  3. Gradual Typing: Add type annotations incrementally
  4. Modern Features: Adopt pattern matching, modules, etc. as desired

Standards Compliance

R7RS Deviations

Lambdust has minimal deviations from R7RS, all documented:

  • Type System: Optional type annotations (purely additive)
  • Effect System: IO operations tracked in types (opt-in)
  • Modules: Enhanced module system (backward compatible)
  • Syntax: Additional syntax forms (non-conflicting)

Compatibility Mode

Use (import (r7rs strict)) to ensure 100% R7RS compliance with no Lambdust extensions. This mode is useful for testing compatibility with other implementations.
