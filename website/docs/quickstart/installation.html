Installation

Lambdust provides multiple installation methods across Windows, macOS, and Linux. Choose the method that best fits your development environment.

System Requirements: x86_64 or ARM64, 4GB RAM, 2GB disk space

Quick Install

One-Line Install (Recommended)

# macOS and Linux
curl -sSf https://get.lambdust.org | sh

# Windows (PowerShell)
iwr -useb get.lambdust.org/win | iex

The installer will automatically detect your system, download the latest version, and add Lambdust to your PATH.

Platform-Specific Installation

macOS

Homebrew (Recommended)

# Install via Homebrew
brew tap lambdust/tap
brew install lambdust

# Verify installation
lambdust --version

MacPorts

# Install via MacPorts
sudo port install lambdust

# Update MacPorts first if needed
sudo port selfupdate

Direct Download

# Download and install manually
curl -L https://github.com/lambdust/lambdust/releases/latest/download/lambdust-macos.tar.gz | tar xz
sudo mv lambdust /usr/local/bin/

Linux

Package Managers

# Ubuntu/Debian (APT)
curl -fsSL https://get.lambdust.org/linux/apt-key.gpg | sudo apt-key add -
echo "deb https://get.lambdust.org/linux/apt stable main" | sudo tee /etc/apt/sources.list.d/lambdust.list
sudo apt update && sudo apt install lambdust

# Fedora/CentOS (DNF/YUM)
sudo dnf config-manager --add-repo https://get.lambdust.org/linux/rpm/lambdust.repo
sudo dnf install lambdust

# Arch Linux (AUR)
yay -S lambdust
# or
paru -S lambdust

# openSUSE (Zypper)
sudo zypper addrepo https://get.lambdust.org/linux/rpm/lambdust.repo
sudo zypper install lambdust

Snap Package

# Install via Snap (Universal Linux)
sudo snap install lambdust --classic

# Update
sudo snap refresh lambdust

AppImage

# Download and run AppImage
wget https://github.com/lambdust/lambdust/releases/latest/download/lambdust-linux.AppImage
chmod +x lambdust-linux.AppImage
./lambdust-linux.AppImage

Windows

Windows Package Manager (winget)

# Install via winget
winget install lambdust.lambdust

# Verify installation
lambdust --version

Chocolatey

# Install via Chocolatey
choco install lambdust

# Update
choco upgrade lambdust

Scoop

# Add bucket and install
scoop bucket add lambdust https://github.com/lambdust/scoop-bucket
scoop install lambdust

MSI Installer

  1. Download the latest lambdust-windows.msi from GitHub Releases
  2. Run the installer as Administrator
  3. Follow the installation wizard
  4. Restart your terminal or IDE

Building from Source

For developers who want the latest features or need to modify Lambdust:

Prerequisites

  • Rust: 1.70+ (install via rustup)
  • Git: For cloning the repository
  • LLVM: 15+ (for code generation)
  • CMake: 3.20+ (for building native dependencies)

Build Steps

# Clone the repository
git clone https://github.com/lambdust/lambdust.git
cd lambdust

# Install dependencies
cargo build --release

# Run tests (optional but recommended)
cargo test

# Install globally
cargo install --path .

# Verify installation
lambdust --version

Development Build

# For development (faster builds, debug info)
cargo build

# Run without installing
cargo run -- --version

# Run with debug output
RUST_LOG=debug cargo run -- --help

IDE and Editor Integration

Visual Studio Code

# Install the Lambdust extension
code --install-extension lambdust.lambdust-vscode

# Or search for "Lambdust" in the Extensions panel

Emacs

;; Add to your Emacs configuration
(use-package lambdust-mode
  :ensure t
  :mode "\\.ldust\\'")

Vim/Neovim

" Install via vim-plug
Plug 'lambdust/vim-lambdust'

" Or via Vundle
Plugin 'lambdust/vim-lambdust'

IntelliJ IDEA

  1. Open Settings → Plugins
  2. Search for "Lambdust"
  3. Install the Lambdust Language Plugin
  4. Restart IntelliJ IDEA

Docker Installation

For containerized development or CI/CD:

# Pull the official image
docker pull lambdust/lambdust:latest

# Run interactively
docker run -it lambdust/lambdust:latest

# Run a script
docker run -v $(pwd):/workspace lambdust/lambdust:latest /workspace/script.ldust

# Development container with volume mount
docker run -it -v $(pwd):/code -w /code lambdust/lambdust:latest bash

Development Dockerfile

FROM lambdust/lambdust:latest

# Install additional tools
RUN apt-get update && apt-get install -y \
    git \
    curl \
    build-essential

# Set working directory
WORKDIR /app

# Copy your project
COPY . .

# Install dependencies (if using a package manager)
RUN lambdust install

CMD ["lambdust", "repl"]

Verification and Testing

After installation, verify everything is working correctly:

Installation Verification

# Check version
lambdust --version

# Run the REPL
lambdust repl

# Execute a simple program
echo '(display "Hello, Lambdust!")' | lambdust

# Check available commands
lambdust --help

# Run built-in tests
lambdust test --stdlib

Common Issues and Solutions

PATH Issues

If lambdust command is not found after installation:

  • macOS/Linux: Add ~/.lambdust/bin to your PATH
  • Windows: Restart your terminal or add installation directory to PATH manually

Permission Errors

# Linux/macOS: Fix permissions if needed
sudo chown -R $USER ~/.lambdust
chmod +x ~/.lambdust/bin/lambdust

# Windows: Run installer as Administrator

Missing Dependencies

# Install system dependencies on Ubuntu/Debian
sudo apt install build-essential libssl-dev pkg-config

# On macOS with Homebrew
brew install openssl pkg-config

# On Windows, use the MSI installer which includes all dependencies

Updating Lambdust

Keep your Lambdust installation up to date:

# Using the built-in updater
lambdust update

# Or reinstall using your package manager
brew upgrade lambdust          # macOS Homebrew
sudo apt update && sudo apt upgrade lambdust  # Ubuntu/Debian
winget upgrade lambdust        # Windows

Uninstallation

If you need to remove Lambdust:

# Package manager uninstall
brew uninstall lambdust        # macOS Homebrew
sudo apt remove lambdust       # Ubuntu/Debian
winget uninstall lambdust      # Windows

# Manual cleanup
rm -rf ~/.lambdust             # Remove user data
# Remove from PATH if manually added
