Quick Start Guide

Welcome to Lambdust! This guide will get you up and running with the pure functional programming language that combines mathematical elegance with practical modern features.

Installation

From Source (Recommended)

Building from source ensures you get the latest features and optimizations:

Clone and Build
# Clone the repository
git clone https://github.com/lambdust-lang/lambdust.git
cd lambdust

# Build in release mode
cargo build --release

# Install system-wide (optional)
cargo install --path .

System Requirements

  • Rust: 1.75.0 or later
  • Memory: 2GB RAM minimum, 4GB recommended
  • Storage: 500MB for source and build artifacts
  • Platform: Linux, macOS, Windows (WSL recommended)

Your First Lambdust Program

Let's start with the classic "Hello, World!" example:

hello.ldust

;; Hello World in Lambdust
(define main : (IO Unit)
  (lambda ()
    (println "Hello, World!")))

;; Run the program
(main)

Save this as hello.ldust and run it:

lambdust hello.ldust

Interactive REPL

Lambdust includes a powerful interactive REPL (Read-Eval-Print Loop) for experimentation:

Starting the REPL
$ lambdust
Lambdust 0.2.0 - Pure Functional Programming Language
Type :help for available commands

λ>

Basic REPL Usage

λ> (+ 2 3)
5

λ> (define square (lambda (x) (* x x)))
square

λ> (square 7)
49

λ> (map square '(1 2 3 4 5))
(1 4 9 16 25)

REPL Commands

  • :help - Show available commands
  • :type expr - Show the type of an expression
  • :load file.ldust - Load a source file
  • :reload - Reload the last loaded file
  • :quit or Ctrl+D - Exit the REPL

Basic Syntax Overview

Data Types

;; Numbers
42           ; Integer
3.14159      ; Real
1/3          ; Rational
2+3i         ; Complex

;; Strings and Characters
"Hello"      ; String
#\A          ; Character

;; Booleans
#t           ; True
#f           ; False

;; Lists
'(1 2 3)     ; List of integers
'(a b c)     ; List of symbols

Function Definition

;; Simple function
(define add (lambda (x y) (+ x y)))

;; With type annotation
(define add : (Number → Number → Number)
  (lambda ((x : Number) (y : Number))
    (+ x y)))

;; Shorthand syntax
(define (add x y) (+ x y))

Conditional Expressions

;; Basic if expression
(if (> x 0) "positive" "non-positive")

;; Multi-way conditional
(cond
  [(< x 0) "negative"]
  [(= x 0) "zero"]
  [else "positive"])

;; Pattern matching
(match lst
  [() "empty"]
  [(cons x xs) (format "head: ~a" x)])

Gradual Typing in Practice

One of Lambdust's key features is gradual typing. Start dynamic and add types incrementally:

Evolution of a Function

;; Step 1: Start dynamic
(define factorial
  (lambda (n)
    (if (<= n 1) 1
        (* n (factorial (- n 1))))))

;; Step 2: Add input type
(define factorial
  (lambda ((n : Integer))
    (if (<= n 1) 1
        (* n (factorial (- n 1))))))

;; Step 3: Full type annotation
(define factorial : (Integer → Integer)
  (lambda ((n : Integer))
    (if (<= n 1) 1
        (* n (factorial (- n 1))))))

Working with Effects

Lambdust tracks side effects in the type system using monads:

;; Pure function
(define pure-add : (Integer → Integer → Integer)
  (lambda (x y) (+ x y)))

;; Function with I/O effects
(define interactive-add : (IO Integer)
  (lambda ()
    (do-io
      [x ← (read-integer "Enter first number: ")]
      [y ← (read-integer "Enter second number: ")]
      [result ← (pure (+ x y))]
      [_ ← (println (format "Result: ~a" result))]
      (return result))))

Essential Standard Library

List Operations

;; List creation and manipulation
(define numbers '(1 2 3 4 5))
(define doubled (map (lambda (x) (* x 2)) numbers))
(define evens (filter even? numbers))
(define sum (fold-left + 0 numbers))

String Operations

;; String manipulation
(define greeting "Hello, Lambdust!")
(define length (string-length greeting))
(define upper (string-upcase greeting))
(define words (string-split greeting " "))

Higher-Order Functions

;; Function composition
(define (compose f g)
  (lambda (x) (f (g x))))

(define square-then-double
  (compose (lambda (x) (* x 2))
           (lambda (x) (* x x))))

;; Partial application
(define (curry f)
  (lambda (x)
    (lambda (y)
      (f x y))))

(define curried-add (curry +))
(define add-5 (curried-add 5))

Project Structure

For larger projects, organize code using modules:

project.ldust
;; Main project file
(import (prefix math. "math/core"))
(import (prefix io. "io/utils"))

(define main : (IO Unit)
  (lambda ()
    (do-io
      [result ← (pure (math.factorial 10))]
      [_ ← (io.write-file "output.txt" 
                          (number->string result))]
      (println "Computation complete!"))))
math/core.ldust
;; Mathematical utilities module
(module math.core
  (export factorial fibonacci prime?)
  
  (define factorial : (Integer → Integer)
    (lambda ((n : Integer))
      (if (<= n 1) 1
          (* n (factorial (- n 1))))))
  
  (define fibonacci : (Integer → Integer)
    (lambda ((n : Integer))
      (if (< n 2) n
          (+ (fibonacci (- n 1))
             (fibonacci (- n 2)))))))
